Build a Next.js 14 web app (no TypeScript) called “Visa Checklist Builder.”

Core Stack:

Next.js 14

React (JavaScript only — no TypeScript)

Tailwind CSS for styling

LocalStorage for data persistence (no backend needed)

🎯 App Overview

A web-based Visa Checklist Builder for migration agents to manage and customize document checklists per visa type.

The app should allow:

Selecting a visa category (Partner Visa, 482 Temporary Work Visa, Protection Visa, Permanent Employer Sponsored Visa).

Automatically loading a default checklist template for that visa.

Adding, editing, deleting, and reordering checklist categories and items.

Saving customized versions as templates, and reloading them later from localStorage.

🧩 Features Breakdown

1. Visa Selection Dropdown

At the top, include a select box:

Partner Visa

482 Temporary Work Visa

Protection Visa

Permanent Employer Sponsored Visa

On selection:

Load the default checklist for that visa from /data/visaChecklists.js.

If a saved template exists for that visa, display an option to load it instead.

2. Checklist UI

Each visa checklist should display multiple collapsible categories.

Each category card should include:

Inline editable title (category name).

Add Item button.

Delete Category (🗑) button.

Items below (collapsible list).

3. Item Features

Each item should include:

Editable text (contenteditable).

Delete button.

Items should support drag-and-drop reordering (using libraries like react-beautiful-dnd or @dnd-kit/core).

4. Add New Categories & Items

Add a “+ Add Category” button at the bottom of the checklist.

Inside each category, the “Add Item” button should append a new editable checklist item.

5. Save Template Functionality

Include a “💾 Save Checklist as Template” button.

On click:

Save the current state (categories + items) into localStorage, grouped by visa type.

Example: localStorage.setItem('template_partnerVisa', JSON.stringify(checklistData)).

When the same visa type is selected later, show a dropdown:

“Default Template”

“Saved Template”

Selecting “Saved Template” should load the previously saved custom checklist.

6. Save Button

Include a final “Save Checklist” button that saves all current changes to localStorage (even without naming as a new template).

🧠 Logic & Behavior

Maintain checklist data in React state (useState).

Use useEffect to sync state changes to localStorage.

Each visa type should have its own default JSON template (from /data/visaChecklists.js).

When user modifies a checklist, it should not affect the default template — changes are stored separately.

Templates should persist between browser sessions.
